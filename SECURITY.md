# Security

This plugin credits real payments. The daemon is watch-only and holds no key, but a detection bug can mark an invoice paid without payment, or give one customer's payment to another invoice. Please report a security problem privately, not in a public issue.

- Use **Security → Report a vulnerability** on this repository (GitHub private vulnerability reporting).
- Say what an attacker can do, what they need, and how to reproduce it.
- Test only against your own installation or devnet. Never against someone else's Bitcart host.

Ordinary bugs and improvements are welcome as normal issues and pull requests.
